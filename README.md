# চাকরি আবেদন সার্ভিস প্ল্যাটফর্ম (Job Application & CV Platform)

বাংলাদেশের সরকারি, আধা-সরকারি ও অন্যান্য চাকরির নিয়োগ বিজ্ঞপ্তি প্রকাশ, চাকরিপ্রার্থীদের ক্যানোনিকাল সিভি প্রস্তুতকরণ, Teletalk অনলাইন আবেদন অটোমেশন ও পেমেন্ট ট্র্যাকিং প্ল্যাটফর্ম।

---

## 📌 মূল ফিচারসমূহ

1. **পাবলিক পোর্টাল:**
   - চলমান সকল সরকারি ও অন্যান্য সার্কুলার তালিকা, ক্যাটাগরি ও ডেডলাইন ফিল্টার।
   - ২০টি করে সার্কুলার পেজিনেশন ও টাইটেল দিয়ে রিয়েল-টাইম সার্চ।
   - জরুরি ডেডলাইন সতর্কতা (আজ ও আগামীকাল শেষ হতে যাওয়া সার্কুলার)।
   - বাংলা স্লাগ সাপোর্ট ও SEO মেটাডাটা (`react-helmet-async`)।
   - পরীক্ষার সময়সূচি ও ফলাফল নোটিশ বোর্ড।

2. **প্রার্থী ও সিভি সিস্টেম (`/cv`):**
   - মাস্টার স্পেকের ক্যানোনিকাল ৬৪ জেলা ও উপজেলা ক্যাসকেড ড্রপডাউন।
   - শিক্ষা যোগ্যতা (SSC, HSC, ডিপ্লোমা, অনার্স, মাস্টার্স ও অন্যান্য)।
   - ছবি (300×300, ≤100KB) ও স্বাক্ষর (300×80, ≤60KB) ব্রাউজারে HTML5 Canvas দিয়ে স্বয়ংক্রিয় রিসাইজ ও কম্প্রেশন।
   - সিভি সম্পূর্ণতার শতকরা হার (Completeness Bar) ও অবশিষ্ট ফিল্ডের রিয়েল-টাইম তালিকা।
   - ১০০% সিভি পূর্ণ না হলে সরাসরি আবেদন ব্লক ও দিকনির্দেশনা।

3. **৫-ধাপের আবেদন ও পেমেন্ট পাইপলাইন:**
   - **Waiting:** প্রার্থী পেমেন্ট ট্রানজ্যাকশন আইডি (bKash/Rocket) দিয়ে আবেদন সাবমিট করার পর অপেক্ষমাণ তালিকা।
   - **Apply Now:** পেমেন্ট যাচাই শেষে অ্যাডমিন Teletalk লিংকে গিয়ে অটোফিল বা ম্যানুয়াল সাবমিট করে সফট কপি PDF আপলোড করেন।
   - **Check Application:** প্রার্থী তার ড্যাশবোর্ডে সফট কপি দেখে "সব ঠিক আছে" অথবা "সংশোধন দরকার" (নোট সহ) জানাতে পারেন।
   - **Payment Now:** সরকারি ফি টেলিটকের মাধ্যমে পরিশোধের পর চূড়ান্ত কপি আপলোড।
   - **Applied (Complete):** প্রার্থী পেইড কপি ডাউনলোড করতে পারবেন।

4. **অ্যাডমিন প্যানেল (`/admin`):**
   - পাইপলাইনের প্রতিটি ধাপে আবেদন ফিল্টারিং ও পরিচালনা।
   - অনন্য ট্রানজ্যাকশন আইডি ভ্যালিডেশন (ডুপ্লিকেট TrxID সম্পূর্ণ ব্লক)।
   - প্রার্থীকে এক ক্লিকে WhatsApp-এ বার্তা পাঠানোর অপশন।
   - File System Access API দিয়ে লোকাল ফোল্ডারে সমস্ত আবেদন JSON ও CSV এক্সপোর্ট (Excel UTF-8 BOM সহ)।

## 🛠 প্রযুক্তি ও ডিপেনডেন্সি

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS
- **Routing:** React Router v7
- **Database & Auth:** Google Firebase (Firestore Database, Firebase Authentication, Firebase Storage)
- **Icons:** Lucide React
- **Sanitization & Security:** DOMPurify

## ⚙️ এনভায়রনমেন্ট ভ্যারিয়েবল (.env)

প্রজেক্টের রুটে `.env` ফাইল তৈরি করুন (বা `.env.example` থেকে কপি করুন):

```bash
# মোবাইল নম্বরকে ভার্চুয়াল Firebase Auth ইমেইলে রূপান্তরের ডোমেন সাফিক্স
VITE_USER_EMAIL_DOMAIN="@users.app.local"

# Firebase কনফিগারেশন (firebase-applet-config.json থাকলে স্বয়ংক্রিয় লোড হয়)
VITE_FIREBASE_API_KEY=""
VITE_FIREBASE_AUTH_DOMAIN=""
VITE_FIREBASE_PROJECT_ID=""
VITE_FIREBASE_STORAGE_BUCKET=""
VITE_FIREBASE_MESSAGING_SENDER_ID=""
VITE_FIREBASE_APP_ID=""
```

## 🔐 কীভাবে প্রথম অ্যাডমিন অ্যাকাউন্ট তৈরি করবেন

সিকিউরিটির খাতিরে সাধারণ ইউজাররা রেজিস্ট্রেশন করলে স্বয়ংক্রিয়ভাবে `role: 'user'` পায় এবং অ্যাডমিন প্যানেল সম্পূর্ণরূপে লক থাকে। প্রথম অ্যাডমিন তৈরির ধাপগুলো:

1. **Firebase Console**-এ যান:
   - আপনার প্রোজেক্ট নির্বাচন করুন এবং **Authentication** > **Users** ট্যাবে যান।
   - **Add User** বাটনে ক্লিক করে একটি ইমেইল ও পাসওয়ার্ড দিন (যেমন: `admin@studyonlinebd.com` এবং একটি শক্তিশালী পাসওয়ার্ড)।
   - তৈরিকৃত ইউজারের **User UID** কপি করে নিন (যেমন: `A1b2C3d4E5f6G7...`)।

2. **Firestore Database**-এ অ্যাডমিন প্রিভিলেজ প্রদান:
   - Firestore Database সেকশনে যান।
   - `admins` নামের কালেকশনে যান (না থাকলে কালেকশন তৈরি করুন: Collection ID: `admins`)।
   - **Add Document**-এ ক্লিক করুন:
     - **Document ID:** ইউজারের কপি করা `UID` পেস্ট করুন।
     - ফিল্ড যোগ করুন:
       - `role`: string -> `admin`
       - `createdAt`: timestamp -> `current timestamp`
   - সেভ করুন।

3. **অ্যাডমিন লগইন:**
   - ব্রাউজারে `/admin/login` ঠিকানায় যান।
   - আপনার নির্ধারিত ইমেইল ও পাসওয়ার্ড প্রদান করে অ্যাডমিন ড্যাশবোর্ডে প্রবেশ করুন।

| ৪. অ্যাডমিন রাউট প্রোটেকশন | `src/components/auth/AdminRoute.tsx`, `firestore.rules` | নন-অ্যাডমিন ইউজার অ্যাডমিন পেজ দেখতে পারে না এবং Firestore রুলস দ্বারা সার্ভার লেভেলেও সম্পূর্ণ সুরক্ষিত। |
| ৫. স্পেক ৬ অনুযায়ী স্ট্যাটাস ট্রানজিশন | `src/utils/statusTransitions.ts`, `firestore.rules` | নির্ধারিত ম্যাট্রিক্সের বাইরে কোনো স্ট্যাটাস বদল কঠোরভাবে ব্লক করা হয়েছে। |
| ৬. ট্রানজ্যাকশন আইডি ডুপ্লিকেট প্রতিরোধ | `src/pages/user/ApplicationPaymentPage.tsx` | Firestore Transaction ব্যবহার করে `trxIds/{trxId}` কালেকশনে ইউনিকনেস নিশ্চিত করা হয়েছে। |
| ৭. ইউনিক ৮-১০ ডিজিট অ্যাপ্লিকেশন আইডি | `src/utils/idGenerator.ts` | `counters/{yyyymm}` ডকুমেণ্টের অ্যাটমিক ট্রানজ্যাকশনের মাধ্যমে অটো-ইনক্রিমেন্টাল আইডি তৈরি হয়। |

## 🌐 ব্রাউজার সামঞ্জস্যতা নোট

- **File System Access API (ফোল্ডারে সরাসরি এক্সপোর্ট):** শুধুমাত্র Google Chrome, Microsoft Edge, Opera এবং আধুনিক Chromium-ভিত্তিক ব্রাউজারে কাজ করে। Firefox বা Safari-তে স্বয়ংক্রিয়ভাবে সরাসরি স্ট্যান্ডার্ড ডাউনলোড ফলব্যাক কার্যকর হবে।
- **অন্যান্য সকল ফিচার:** Chrome, Firefox, Edge, Safari এবং মোবাইল ব্রাউজারে (Android/iOS) সমানভাবে কার্যকর।
